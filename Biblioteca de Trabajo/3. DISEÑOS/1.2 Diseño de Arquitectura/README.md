## 📝 Descripción del Artefacto

El **Diseño Arquitectónico** documenta la arquitectura de 3 capas del sistema, incluyendo:

- 🏗️ **Capa de Presentación:** Interfaces de usuario para gestión de préstamos y devoluciones.  
- ⚙️ **Capa de Lógica de Negocio:** Controladores y servicios que aplican la lógica de negocio del sistema.  
- 💾 **Capa de Datos:** Persistencia en MongoDB, incluyendo esquemas y consultas.  
- 📌 **Observaciones:**  
  - V1.0: Primera versión de la arquitectura del proyecto para el préstamo de dispositivos.  
  - V2.0: Versión aprobada y consolidada de la arquitectura.
