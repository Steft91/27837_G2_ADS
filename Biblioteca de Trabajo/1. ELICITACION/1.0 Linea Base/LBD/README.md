## 🎨 Línea Base LBD – Diseño

La **Línea Base de Diseño (LBD)** contiene los artefactos gráficos que representan el diseño funcional del sistema web de **gestión de préstamos de dispositivos institucionales de la ESPE**, asegurando coherencia entre los requisitos definidos y la solución propuesta.

### 🧩 Descripción del Artefacto

La **Línea Base de Diseño** incluye:

- Diagrama de Casos de Uso del sistema de préstamos
- Representación visual de la interacción entre usuarios y el sistema
- Identificación clara de actores (Estudiante, Docente, Administrativo, Técnico)
- Relación directa con los requisitos funcionales definidos en el SRS
