## 📝 Descripción del Artefacto

El diagrama de componentes incluye:

- 📦 **Componentes del sistema:** Backend (API, módulos de negocio, persistencia), Frontend (interfaz de usuario, comunicación con API).  
- 🔌 **Interfaces proporcionadas y requeridas:** Métodos expuestos por cada componente y dependencias necesarias para su correcto funcionamiento.  
- 🔗 **Dependencias entre componentes:** Relaciones de uso entre módulos de backend y frontend.  
- 🗂️ **Organización modular del sistema:** Estructura del sistema dividida en componentes independientes para facilitar mantenimiento y escalabilidad.
