## 📝 Descripción del Artefacto

Las **Historias de Usuario** describen las funcionalidades del sistema desde la perspectiva de los distintos roles (estudiantes, docentes, administrativos y técnico), e incluyen:

- Formato estándar: *Como [rol], quiero [funcionalidad], para [beneficio]*  
- Criterios de aceptación claros y verificables  
- Prioridad y estimación para planificación de sprints  
- Dependencias entre historias para la construcción del backlog
