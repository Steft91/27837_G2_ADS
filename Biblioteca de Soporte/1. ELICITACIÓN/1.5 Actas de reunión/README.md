## 📝 Descripción del Artefacto

Las actas de reunión documentan de manera formal los encuentros realizados durante la etapa de **Elicitación** del proyecto de **Préstamo de Dispositivos Audiovisuales**, incluyendo:

- 🤝 Reuniones con el cliente y stakeholders  
- 📌 Definición de funcionalidades: registro de préstamos y devoluciones, historial de transacciones, alertas por retrasos, y gestión de usuarios  
- ✅ Acuerdos y compromisos sobre interfaces, permisos de usuarios y políticas de préstamo  
- 🔍 Registro de consentimiento y validación de requerimientos  

Este artefacto permite mantener trazabilidad y respaldo de las decisiones acordadas, asegurando que el sistema cumpla con los requerimientos funcionales y no funcionales definidos.
