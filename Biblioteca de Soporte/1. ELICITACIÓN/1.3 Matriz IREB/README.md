## 📝 Descripción del Artefacto

La **Matriz de Trazabilidad IREB** permite mantener la trazabilidad bidireccional entre:

- Requisitos de usuario y requisitos del sistema  
- Requisitos funcionales y no funcionales  
- Requisitos y casos de uso  
- Requisitos y componentes del sistema  
- Requisitos y criterios de validación  

Esta matriz garantiza que todos los requisitos estén correctamente cubiertos y controlados a lo largo del ciclo de vida del proyecto.
