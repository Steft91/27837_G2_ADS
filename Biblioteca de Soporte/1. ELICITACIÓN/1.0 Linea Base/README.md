## 🧩 Descripción del Sistema de Líneas Base

El proyecto utiliza un esquema de **cuatro (4) líneas base** para la correcta gestión de la configuración del software:

- **LBA (Análisis):** Contiene los artefactos generados durante la fase de análisis, como actas de reunión, levantamiento de requisitos y documentación del problema.
- **LBC (Código):** Almacena el código fuente del sistema web, incluyendo el Frontend como interfaz de usuario y el Backend encargado de la lógica de negocio, validaciones e integración con el sistema Banner.
- **LBD (Diseño):** Incluye diagramas de arquitectura, flujo del sistema, casos de uso y modelos de diseño que representan la solución propuesta.
- **LBR (Requisitos):** Contiene el documento SRS con requisitos funcionales, no funcionales, historias de usuario y priorización del backlog.
