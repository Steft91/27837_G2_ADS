## 📝 Descripción del Artefacto

El documento **SRS** contiene la especificación formal y detallada de los requisitos del sistema de préstamos de dispositivos, incluyendo:

- Descripción general del sistema y su propósito
- Identificación de actores y roles (estudiantes, docentes, administrativos y técnico)
- Requisitos funcionales priorizados para el backlog
- Requisitos no funcionales (seguridad, rendimiento, usabilidad y disponibilidad)
- Restricciones, supuestos y dependencias del sistema
- Matriz de trazabilidad de requisitos
