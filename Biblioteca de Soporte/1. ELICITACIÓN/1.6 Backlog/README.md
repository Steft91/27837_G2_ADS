## 📝 Descripción del Artefacto

El **Product Backlog** contiene:

- 📋 Lista priorizada de historias de usuario relacionadas con el préstamo y devolución de dispositivos audiovisuales.  
- ⏱️ Estimaciones de esfuerzo (story points) para cada historia.  
- 📆 Asignación de ítems a sprints.  
- 🔄 Estado de cada ítem (pendiente, en progreso, completado).  

Este artefacto permite gestionar de forma clara y estructurada las funcionalidades del sistema, asegurando trazabilidad y visibilidad del progreso.
